На бесплатном уровне обслуживания GitHub не позволяет размещать публичный GitHub Pages в приватном репозитории. Поэтому мы используем обходное решение: создали отдельный публичный репозиторий специально для размещения собранной версии проекта и настроили автоматическую публикацию через GitHub Actions.
